# 17 — Inisialisasi tabel database

`src/database.rs` menyiapkan tabel yang dipakai langsung oleh query aplikasi. Fungsi `initialize(pool: &PgPool)` dipanggil dari `main.rs` setelah koneksi pool berhasil dibuat dan sebelum server Axum mulai menerima request.

## Tabel yang disiapkan

Fungsi menjalankan `CREATE TABLE IF NOT EXISTS` untuk:

| Tabel | Kolom | Alasan |
|---|---|---|
| `barang` | `id INTEGER GENERATED BY DEFAULT AS IDENTITY PRIMARY KEY` | Model memakai `id: i32`, dan query `INSERT` tidak mengirim nilai `id`, sehingga database perlu menghasilkan ID. |
| | `nama TEXT NOT NULL` | Model membaca `nama` sebagai `String`; query insert/update mengisi kolom ini. |
| | `stok INTEGER NOT NULL` | Model membaca dan menulis `stok` sebagai `i32`. |
| | `harga NUMERIC NOT NULL` | Model memakai `Decimal`, yang dipetakan SQLx ke PostgreSQL `NUMERIC`. |
| `users` | `username TEXT PRIMARY KEY` | Register dan login mencari berdasarkan username; primary key memastikan username unik. |
| | `password TEXT NOT NULL` | Register menyimpan dan login membandingkan nilai password sebagai string. |

`riwayat_stok` tidak dibuat karena tidak ada query atau model dalam source saat ini yang memakainya, dan definisi schema aktualnya belum tersedia.

## Perilaku saat startup

`main.rs` memberikan referensi ke pool yang sudah ada; fungsi ini tidak membuat pool baru. Tabel dibuat berurutan, `barang` lalu `users`. Error dikembalikan dengan nama tabel, kemudian `main` menghentikan proses startup. Router dan listener baru disiapkan setelah inisialisasi sukses.

## Batasan `IF NOT EXISTS`

Perintah ini hanya membuat tabel jika nama tabel belum ada. Jika tabel sudah ada, PostgreSQL tidak membandingkan kolom atau memperbaiki tipe, constraint, dan relasinya. Karena itu, tabel existing dengan struktur yang berbeda bisa tetap menyebabkan query aplikasi gagal. Fungsi ini tidak menjalankan `ALTER`, `DROP`, atau mengubah isi tabel.

Objek yang dibuat melalui fungsi ini adalah schema untuk instalasi baru yang mengikuti kebutuhan query/model saat ini. Struktur tabel existing tidak diperiksa atau diselaraskan otomatis.
